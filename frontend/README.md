# Frontend

## Setup

### Install Dependencies

```
npm install
```

### Set environment variables

```
cp .env.example .env
```

set VITE_API_BASE_URL in .env to the backend URL

## Running

```
npm run dev
```

now it the frontend is available at `http://localhost:5173/`

## Linting and Formatting

```
npm run lint
npm run format
```
